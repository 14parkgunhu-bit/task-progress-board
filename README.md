# 업무 진행판

> 행정 업무를 **할 일 단위로 쪼개고**, **진행 상황을 한눈에 보고**, **보고용 5줄 요약**까지 만들어 주는 개인용 웹앱

- **접속 주소**: https://task-progress-board.vercel.app
- **GitHub 저장소**: https://github.com/14parkgunhu-bit/task-progress-board
- **만든 사람**: 박건후 · 바이브 코딩 실습 프로젝트 (Claude Code + Codex)

---

## 왜 만들었나요?

여러 행정 업무를 동시에 맡으면 업무 목록과 진행 상황이 엑셀·메모·메신저에 흩어져요. 그래서 무엇이 어디까지 됐는지 한눈에 보기 어렵고, 마감을 놓치거나 상급자에게 보고할 때마다 자료를 다시 정리해야 해요. 새로 맡은 업무는 어떤 단계로 나눠야 할지 막막하기도 하고요.

**업무 진행판**은 이 불편을 한 화면에서 해결해요.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 📋 **업무 등록·진행판** | 업무명·마감일·메모를 등록하고 할 일을 체크하면 진행률(%)과 상태(정상·임박·지연·완료)가 자동으로 바뀌어요. 지연 → 임박 → 정상 → 완료 순서로 정렬돼요. |
| 🤖 **AI 단계 나누기** | 업무를 3~7개의 할 일로 나눠 **제안**해요. 고친 뒤 [저장]을 눌러야 반영되고, 기존 할 일이 있으면 [뒤에 추가]/[바꾸기]를 고를 수 있어요. |
| 📝 **AI 진행 요약** | 진행판 전체를 상급자 보고용 5줄로 요약해요. 앱이 직접 계산한 값과 **한 줄씩 대조해 통과한 요약만** 보여줘요. |
| 🔍 **임박·지연 필터** | 마감이 가까운 업무나 지난 업무만 골라 볼 수 있어요. |
| 💾 **백업·복원** | 진행판을 JSON 파일로 내보내고, 미리보기와 동의를 거쳐 되살릴 수 있어요. 파일은 브라우저 안에서만 처리해요. |
| 🛡️ **안전장치** | AI가 실패해도 직접 입력·기본 요약으로 이어서 쓸 수 있어요. 늦게 온 AI 응답이 내가 고친 내용을 덮어쓰지 않아요. |

## 데이터와 보안

- **업무 데이터는 내 브라우저(localStorage)에만 저장**돼요. 서버나 DB에 저장하지 않아요.
- AI 기능을 쓸 때만 업무명·메모가 앱 서버를 거쳐 **해외 AI 제공자(OpenAI)로 전송**돼요. **개인정보와 비공개·대외비 문서 내용은 입력하지 마세요.** 요약에는 메모와 할 일 제목을 보내지 않아요.
- 공개 주소의 AI 기능은 **접근 코드**가 있어야 쓸 수 있어요(접근 코드가 없어도 진행판·기본 요약·필터·백업은 쓸 수 있어요). 접속자별 호출 횟수 제한(1분 5회·하루 50회)과 틀린 코드 시도 제한도 있어요.
- API 키는 서버에서만 읽고 브라우저에는 노출되지 않아요. 검색 사이트에도 노출되지 않게(noindex) 설정했어요.

## 기술 스택

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · OpenAI API · Vercel

새로 설치한 외부 라이브러리 없이 Next.js와 Node.js 기본 기능만 썼어요. 자동 점검은 Node 내장 테스트(`node --test`)로 돌려요.

## 직접 실행해 보기

1. 패키지 설치
   ```bash
   npm install
   ```
2. 프로젝트 루트에 `.env` 파일을 만들고 값을 직접 입력하세요. (`.env`는 Git에 올라가지 않아요.)

   | 이름 | 필수 | 설명 |
   |---|---|---|
   | `OPENAI_API_KEY` | 필수 | AI 호출용 키 (서버에서만 사용) |
   | `APP_ACCESS_CODE` | 배포할 때 필수 | 접근 코드. 영어·숫자 무작위 16자 이상. 개발 중에 비워 두면 검사를 건너뛰고, 배포 환경에서 비어 있으면 AI 요청이 모두 막혀요. |
   | `OPENAI_MODEL` | 선택 | AI 모델 이름 (기본값 `gpt-4.1-mini`) |

3. 개발 서버 실행 후 http://localhost:3000 접속
   ```bash
   npm run dev
   ```

접근 코드를 설정했다면 화면 오른쪽 위 **[접근 코드 입력]** 에 같은 값을 넣어야 AI 기능이 동작해요.

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 실행 |
| `npm test` | 계산·검증 함수 자동 점검 |
| `npm run lint` | 코드 검사 |
| `npm run build` | 배포용 빌드 |

## 폴더 구조

| 위치 | 내용 |
|---|---|
| `app/` | 화면(`page.tsx`)과 서버 창구(`api/steps`, `api/summary`) |
| `components/` | 화면 조각 (업무 폼, 업무 카드, 요약 패널, 백업 패널 등) |
| `hooks/` | 화면 상태 관리 (`useBoard`) |
| `lib/` | 진행률·상태·요약·검증 같은 규칙 (순수 함수) |
| `lib/client/` | 브라우저 전용 (저장소, 서버 호출) |
| `lib/server/` | 서버 전용 (AI 호출, 접근 코드, 호출 제한) |
| `tests/` | 자동 점검 |
